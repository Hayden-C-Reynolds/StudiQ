# StudiQ — AI Study Companion

StudiQ is a full stack AI-powered study companion built 
for students who want to actually learn, not just get answers.

## Features
- **AI Study Plan Generator** — Upload your syllabus and 
get a personalized day-by-day study schedule with deadlines 
automatically extracted
- **AI Tutor** — Socratic tutoring that guides you through 
problems with hints, explanations, and YouTube video 
suggestions instead of just giving answers. Supports text, 
PDF, and image uploads
- **Practice Test Generator** — Custom practice tests by 
topic, difficulty, and format with instant feedback in 
Quiz Mode or full exam simulation in Mock Test Mode

## Tech Stack
- Frontend: React, KaTeX
- Backend: Python, FastAPI
- AI: Anthropic Claude API (Claude Sonnet)
- APIs: YouTube Data API v3
